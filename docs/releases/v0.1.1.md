# JSONC Merge v0.1.1 — binary preview

This pre-release adds downloadable executables and a complete, bundled demo.

- Linux x64: static musl build.
- macOS: separate Apple Silicon and Intel builds, with a macOS 13.0 deployment target.
- Windows x64: static C runtime build.
- Every archive includes the executable, example inputs and expected result,
  documentation, build metadata, a file manifest and license notices.
- `SHA256SUMS` contains the checksums for all four archives.

The release workflow runs Rust tests for each target, inspects the resulting
binary, extracts the package into a clean directory and checks its version,
validation, merge, plan, conflict and Git-driver behavior before creating this
draft. Publishing remains a manual owner action after all checks finish.

See the [installation guide](https://github.com/KavishGajjar/jsonc-merge-rs/blob/v0.1.1/docs/install.md)
for choosing an archive, verifying its checksum and running the included demo.
No Rust installation is needed for the downloaded executable. macOS/Windows
downloads are not distributor-signed or notarized.

The merge API and semantics are unchanged from v0.1.0. This remains a preview:
unconfigured arrays are atomic, record identities are explicit, and automatic
rename inference and multi-file merging are outside v1.
